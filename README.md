# 🏆 Tier List

Веб-приложение для создания тир-листов из собственных фотографий. Работает полностью в браузере: без сервера, сборки и сторонних библиотек (чистые HTML, CSS и JavaScript).

## ✨ Возможности

- Загрузка нескольких локальных изображений сразу, из каждого создаётся карточка
- Перетаскивание карточек из общего пула в таблицу (уровни **S, A, B, C, D**)
- Изменение порядка карточек внутри строки
- Редактируемые названия уровней: вместо букв можно написать любой текст
- Название для всего тир-листа
- Удаление карточек и сброс таблицы (карточки возвращаются в пул)
- Экспорт готовой доски в PNG вместе с названием
- Адаптивный интерфейс и поддержка перетаскивания пальцем на телефонах

## 🛠 Технологии

- **HTML5**: разметка
- **CSS3**: Flexbox, CSS-переменные, медиазапросы для адаптива
- **JavaScript (ES6+)**: Pointer Events для drag-and-drop, Canvas API для экспорта, Blob URL для работы с локальными файлами
- **Google Fonts**: шрифт Ubuntu Mono

## 🚀 Установка и запуск

Сборка не нужна. Достаточно клонировать репозиторий и открыть страницу в браузере.

```bash
git clone https://github.com/<your-username>/tier-list.git
cd tier-list
```

Затем откройте `index.html` в браузере. Для удобной разработки можно использовать расширение **Live Server** в VS Code.

> Шрифт Ubuntu Mono подключается из Google Fonts. Без интернета будет использован запасной моноширинный шрифт.

## 📖 Как пользоваться

1. Введите название тир-листа в поле над таблицей.
2. Нажмите **«+ Добавить фото»** и выберите изображения. Карточки появятся в пуле внизу.
3. Перетащите карточки в нужные строки таблицы. На телефоне сначала зажмите карточку на долю секунды.
4. Чтобы изменить название оценки, нажмите на букву слева, введите свой текст и нажмите Enter.
5. Чтобы удалить карточку, нажмите на крестик в её углу.
6. **«Сбросить таблицу»** возвращает все карточки в пул, названия уровней сохраняются.
7. **«Экспорт в PNG»** (правый верхний угол) скачивает готовую доску как изображение.

## ⚙️ Как это работает

- **Загрузка файлов.** Изображения не отправляются на сервер: для каждого файла создаётся Blob URL через `URL.createObjectURL`, который освобождается при удалении карточки.
- **Drag-and-drop.** Вместо HTML5 Drag and Drop API используются Pointer Events, поэтому одна и та же логика работает и для мыши, и для касаний. На сенсорных экранах перетаскивание начинается после долгого нажатия (~180 мс), чтобы не мешать прокрутке. Во время перетаскивания страница автоматически прокручивается у краёв экрана.
- **Экспорт.** Доска не снимается скриншотом, а рисуется заново на `<canvas>` фиксированного размера (1000 px по ширине). Поэтому результат не зависит от размера экрана и устройства.
- **Адаптив.** Размеры карточек и подписей уровней задаются CSS-переменными `--card-size` и `--label-w`, которые меняются в медиазапросах.

## 🌐 Поддержка браузеров

Работает в актуальных версиях Chrome, Edge, Firefox и Safari, в том числе на мобильных устройствах.

## ⚠️ Ограничения

- Данные не сохраняются: после обновления страницы карточки и расстановка пропадают, поэтому результат стоит сразу экспортировать.
- На iPhone скачивание PNG иногда открывает картинку в новой вкладке, там её можно сохранить долгим нажатием.
